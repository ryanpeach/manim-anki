# Manim-Anki

Some experiments in making [anki](https://apps.ankiweb.net/) decks with [manim](https://www.manim.community/) animations.

## Structure

* `manim_anki` is the library for the common code
* `decks` is a folder of python modules that generate anki decks

## AI Policy

I definitely use AI for this, and also take manim code and inspiration from a variety of sources. This is for speed of development and educational purposes.
